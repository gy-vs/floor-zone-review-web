# 楼层分区核对工作台

本地运行的楼层用途分区审阅页面：先建立楼层外轮廓与不可用区域（柱体、设备间），
再在统一的**米坐标系**里绘制、调整、命名用途分区；重叠、出界、压不可用与未分配
全部由**后端独立做布尔几何判定**，前端只负责编辑与呈现。几何裁剪使用经过验证的
[`polygon-clipping`](https://www.npmjs.com/package/polygon-clipping)，不自行发明裁剪算法。

## 启动

```bash
npm install
npm start          # http://localhost:3000
npm test           # Node 内置测试运行器：几何判定 + API 全流程
```

无需外部数据库、地图服务或系统级可执行文件；保存版本、检查结果与确认记录持久化在
`data/state.json`（可用 `DATA_DIR` 改位置，自动测试使用临时目录）。

初始内置文档就是用于核对的 10m × 8m 矩形楼层：区域甲占 x=0–6、区域乙占 x=5–10，
中间 **1m × 8m = 8m² 的重复带**会在图上红色标出；改成 0–5 / 5–10 无缝相接后
重复带消失（共边相接永远不会产生正面积重叠，判定带 1e-7 m² 的退化阈值）。

## 计算口径（后端 `server/geometry.js`，唯一判定来源）

| 指标 | 含义 |
|---|---|
| 楼层面积 | 楼层外轮廓面积 |
| 不可用面积 | 柱/设备间等落在楼层内部分的**并集**（互相重叠不重复扣） |
| 可分配面积 | 楼层与不可用并集的**布尔差**（支持多洞，不是边框相减） |
| 出界面积 | 分区落在楼层外轮廓之外的部分 |
| 压不可用面积 | 分区落在不可用区域上的部分 |
| 重复占用 | 分区两两在**可用面**上的正面积交集；共边/点接触不算 |
| 已分配 | 各分区落在可用面部分的**去重并集** |
| 未分配 | 可分配面积 − 已分配并集（黄色点斑区域，提示性质） |
| 有效面积 | 分区落在可用面、再扣除与其他分区重复占用后的**独占**面积 |

因此“标称面积之和看起来正确”不再能掩盖问题：出界、压不可用、重复是三类独立阻断问题。
自交（蝴蝶结）多边形会在判定前被识别为阻断，不产生碎片面积结论。

## 使用

- **选择/调整**：点击分区/不可用区域/楼层边界后拖顶点、双击边加中点、整体拖动面；
  左侧面板可改名、改色、按坐标删点。滚轮以光标为锚缩放，拖空白平移；
  浏览器窗口缩放只改视图，不改变任何坐标与面积。
- **绘制**：选择“画用途分区 / 画不可用区域 / 重画楼层”，逐点单击（靠近首点或双击闭合），
  回车完成、Esc 取消。
- **问题核对**：右侧“面积与问题”列出每块区域与涉及的分区；点击问题行会在图上高亮、
  缩放定位并选中第一个相关分区，可直接回到它的顶点继续改。
- 编辑过程中，图上结论来自 `/api/evaluate` 对**未保存草稿**的实时判定，并明确标注
  “不是已保存/已确认结论”；保存版本的结论来自 `/api/check`，两者从不混写。

## 两人轮流编辑与交付（`server/store.js`）

- 保存是乐观并发：请求带 `baseVersion`。若同事已存入更新版本而内容不同，返回 **409**
  并回带服务端文档；服务端**不做任何覆盖**。页面顶部出现冲突条，可在“我的草稿 /
  服务端版本”之间切换对照，再决定以草稿**另存为新版本**或放弃草稿。
- 确认交付只能针对**当前最新保存版本**，且必须存在针对该版本内容指纹（sha256）的
  **新鲜通过检查**：未检查、检查过期、版本已前进，都会被拒绝（旧的“无重叠”结论
  不能冒充新版本的通过证明）。未分配等信息项不阻断，但需在确认框中显式知晓。
- 确认记录不可变；历史版本（含其检查与确认）可在“版本历史”只读查看，刷新页面后
  保存版本、检查与确认状态都从 `data/state.json` 重新查到。继续编辑形成的新草稿
  不会回写旧交付结果。
- 未保存的本地草稿存于浏览器 localStorage 并明确标注其基于的保存版本，永不显示为已交付。

## 目录

```
server/geometry.js    布尔判定（polygon-clipping）、面积口径、自交检测、内容指纹
server/store.js       版本链 / 按内容哈希缓存检查 / 不可变确认 / JSON 持久化
server/validation.js  保存内容结构校验
server/server.js      Express：静态前端 + /api/state|save|evaluate|check|confirm|versions
public/               原生 JS + SVG 工作台（无地图库）
test/geometry.test.js 12 个测试：面积口径、相接/重叠、柱体多洞、冲突、确认时效
```
