# 楼层用途分区审阅工作台

本地运行的单层办公空间分区核对工具：以**米坐标二维多边形**建立楼层外轮廓与不可用区域，
在其中绘制、调整、命名用途分区，并直接在平面上看到 **超出楼层 / 压占不可用 / 重复占用 / 未分配空缺**
四类问题区域及涉及的分区。后端保存草稿版本并**独立给出几何判定**，前端只做实时预览；
检查通过且版本未变化时，才能把某个确切保存版本确认为交付版本。

## 启动

```bash
npm install
npm start          # http://localhost:5173 （可用 PORT=xxxx 改端口）
```

无外部数据库、地图服务或系统级可执行文件；状态保存在 `server/data/state.json`（删除即重置）。

## 测试

```bash
npm test               # Node 内置 test runner：几何内核 + HTTP 端到端（13 项）
npm run verify:browser # 按浏览器 import map 求值前端模块图，验证几何结果
```

## 核对用例（页面工具栏“载入 10×8 核对示例”）

- 楼层 10m × 8m；区域 A 占 x = 0–6m、区域 B 占 x = 5–10m。
- x = 5–6m 的 **1m 宽 × 8m = 8m² 重复带**以橙色斜线标出，问题列表显示该带涉及 A、B。
- 把 A 的两个 x=6 顶点拖到 x=5（两边仅共边相接），重复带消失，且**不会**被记为正面积重叠。
- 在楼层内画不可用小区域后：可分配面积 = 楼层面积 − 不可用面积（真实布尔差），
  右侧“面积对账”恒等校验为 `独占有效 + 重叠 + 空缺 = 可分配面积`。

## 几何口径（前后端共用同一内核 `shared/geometry.js`）

- 坐标一律为米；SVG 仅做线性缩放，顶点位置、面积读数、计算结果都与浏览器缩放无关。
- 布尔运算使用经验证的 [`polygon-clipping`](https://www.npmjs.com/package/polygon-clipping)，不自造裁剪。
- 对“可分配面积（楼层 − 不可用并集）”做增量剖分：剖分单元始终是可分配面积的一个划分，
  每个单元记录覆盖它的分区集合：
  - 0 个分区 → **未分配空缺**（提示）；
  - 1 个分区 → 该分区的**独占有效面积**；
  - ≥2 个分区 → **重复占用**（面积 + 涉及分区列表，天然支持三方以上重叠）。
- 每个分区另外独立给出：标称面积、超出楼层部分、压在不可用区域部分、被重复计入部分。
  因此“标称面积之和看起来对”不能掩盖三类性质不同的问题。
- 共边相接经布尔运算后只产生零面积残片（< 1e-9 m²），被剔除，不计为重叠。
- 校验：顶点数、数字坐标、零面积/共线、非相邻边自交；无效计划无法保存。

## 版本、检查与确认的一致性

- 版本号 `rev = 序号 + 计划内容哈希`（键序无关）；保存采用**乐观锁 baseRev**：
  同事先保存时返回 `409 rev_conflict`，本地草稿原样保留（localStorage），绝不静默覆盖。
  对照后可“放弃草稿改用服务端版本”，或在明确确认后以服务端当前版本为基线覆盖保存（历史版本仍保留）。
- 保存后服务端**后台异步**对该确切版本运行独立检查（可轮询 pending → done），
  检查报告随版本持久化；刷新/重启后保存版本、检查结论、确认状态都能重新查到。
- **确认交付**只认一个确切 rev：确认前强制对该 rev 重新判定；检查未完成、几何无效或版本不匹配
  都会被拒绝——旧版本的“无重叠”结论不能挪用到新版本。
- 已确认版本是不可变快照（“已确认交付版本”标签只读查看）；之后继续编辑只会产生新草稿/新版本，
  不回写旧交付结果。三个标签页明确区分：编辑草稿（本地未保存改动）/ 服务端已保存版本
  （含最近检查）/ 已确认交付版本。

## 页面操作

- 工具栏：重绘楼层、添加不可用区域、添加用途分区（依次点击落点，回到起点或“完成绘制”闭合；0.05m 吸附可关）。
- 选中对象后：拖动蓝色顶点、点击边中点小方块插入顶点，右侧面板可逐点键入米坐标并“定位”。
- 点击图上的问题区域或问题列表项可选中它；涉及的分区以彩色标签列出，点标签即跳到该分区顶点继续修改。
- 任一顶点改动后，重叠、空缺与每区有效面积随同一组米坐标实时更新。

## 目录

```
shared/geometry.js   前后端共享几何内核（校验、布尔运算、剖分分析、面积对账、哈希）
server/store.js      JSON 文件存储：版本历史、按 rev 的检查记录、确认记录
server/index.js      HTTP 服务：静态工作台 + /api/state|save|check|revision|confirm
public/              工作台前端（原生 SVG + ES Module，无框架、无地图库）
test/                几何用例与服务端端到端用例
scripts/             浏览器模块图完整性校验
```
